# Spec Delta

## Purpose

定义 `032player-rs` 桌面客户端基于服务端 EBU R128 响度数据的客户端响度均衡规划、高基准与有界软限幅听感保护、本机双音频后端（`libmpv` 与 `AsioPlayer`）实时及无缝执行、设置持久化与曲目信息诊断展示行为规范。

## ADDED Requirements

### Requirement: 兼容解析服务端响度能力位与曲目原始响度字段
客户端 SHALL 从服务端能力响应与曲目响应中向后兼容地解析响度元数据，并在连接不支持响度的旧版服务端时优雅降级而不影响正常播放。

#### Scenario: 连接支持响度的新版服务端
- **WHEN** 客户端登录并获取 `GET /api/v1/capabilities` 与曲目数据时服务端返回 `features.loudness = true`、`loudness` 统计对象及曲目响度字段
- **THEN** 客户端记录服务端响度能力与曲库中位数参考值，并在曲目模型与队列中保留单曲和专辑的响度物理量

#### Scenario: 连接不支持响度的旧版服务端
- **WHEN** 服务端未返回 `features.loudness` 或曲目缺少响度字段
- **THEN** 客户端正常完成登录与播放，设置页明确提示当前服务器不支持响度均衡且不触发任何错误弹窗

### Requirement: 以高基准与余量感知有界软限幅计算每曲均衡计划避免整体变小体感
开启响度均衡后，客户端 SHALL 根据用户选择的响度目标、对齐方式、峰值保护模式、当前软件音量以及曲目原始响度与真峰值计算每曲均衡计划，并针对「软件音量 100% + 外置 DAC」场景避免因过低基准或过度防削波导致的整体音量骤降与大动态压扁。

#### Scenario: 现代高响度曲目在饱满档仅做轻度纯线性衰减
- **WHEN** 响度均衡开启且设为默认饱满档（`-11.0 LUFS`）、柔和限幅模式、软件音量 100%，播放一首 `-8.0 LUFS` / `+0.5 dBTP` 的曲目
- **THEN** 均衡计划施加 `-3.0 dB` 纯线性增益且不启用限幅器，既避免大幅变小又消除采样间过载

#### Scenario: 轻响度曲目在有界软限幅下被平稳拉齐且不压垮大动态
- **WHEN** 响度均衡开启且设为饱满档（`-11.0 LUFS`）、柔和限幅模式（最大瞬态压限 `3.5 dB`、天花板 `-1.0 dBTP`）、软件音量 100%
- **THEN** 对 `-14.0 LUFS` / `-1.0 dBTP` 曲目施加 `+3.0 dB` 增益并启用 `-1.0 dBTP` 真峰值软限幅器；对 `-22.0 LUFS` / `-1.0 dBTP` 的大动态曲目将增益封顶在 `+3.5 dB` 以保留高潮动态

#### Scenario: 严格防削波模式保持全程纯线性零限幅
- **WHEN** 用户将峰值保护切换为严格防削波模式
- **THEN** 均衡计划将允许的最大瞬态压限设为 `0 dB`，在任何软件音量下均确保合成峰值不超过 `-1.0 dBTP` 且不启用限幅器

#### Scenario: 软件音量低于 100% 时自动利用数字余量减少限幅介入
- **WHEN** 用户将软件音量调低（如 70%，约 `-9.3 dB`）并播放需要正增益的轻响度曲目
- **THEN** 均衡计划在合并软件音量后的有效峰值未超过 `-1.0 dBTP` 时直接施加全额纯线性增益并旁路限幅器

#### Scenario: 尚未分析完的新曲采用保守只降不升回退
- **WHEN** 响度均衡开启但当前播放曲目缺少有效响度元数据
- **THEN** 客户端根据曲库中位数计算保守回退增益（钳制在 `[-6.0, 0.0] dB` 区间，曲库中位数未知时为 `0.0 dB`）且不启用限幅器，防止未分析曲目突然暴响

### Requirement: 智能模式按队列播放上下文自动选择专辑或单曲响度
客户端 SHALL 支持「智能」、「按单曲」与「按专辑」三种对齐方式，使连续聆听整张专辑时保留曲间原本的强弱编排，混播或随机播放时按单曲对齐。

#### Scenario: 顺序播放同一张专辑时智能模式选用专辑响度
- **WHEN** 对齐方式为智能，未开启随机播放，当前曲目位于手动队列区且其相邻前曲或后曲属于同一专辑，且专辑响度可用
- **THEN** 客户端选用该曲的专辑集成响度与专辑真峰值计算增益

#### Scenario: 随机播放或跨专辑混播或相似自动续播时智能模式选用单曲响度
- **WHEN** 对齐方式为智能，且处于开启随机播放、前后相邻曲目不属于同一专辑、或当前曲目位于相似自动续播区中的任一情形
- **THEN** 客户端选用单曲集成响度与单曲真峰值计算增益

#### Scenario: 按专辑模式在缺失专辑响度时安全回退至单曲响度
- **WHEN** 对齐方式为按专辑，但当前曲目仅有单曲响度而缺少专辑响度
- **THEN** 客户端自动回退使用单曲响度与单曲真峰值计算增益

### Requirement: 在本机 libmpv 与 ASIO 双后端一致、实时且无缝执行响度均衡
开启响度均衡后，客户端 SHALL 在普通输出、WASAPI 独占与 ASIO 独占模式下一致生效，与播放/暂停淡入淡出互不干扰，并在无缝切歌和播放中修改设置时平滑生效；关闭响度均衡时恢复音频直通；Sonos 投放不受本机响度均衡影响。

#### Scenario: 播放中实时切换开关或档位即时生效且不产生爆音
- **WHEN** 本机正在通过 `libmpv` 或 `AsioPlayer` 播放曲目，用户在设置页开关响度均衡或切换目标档位 / 对齐方式 / 峰值保护
- **THEN** 新均衡计划立即应用于当前播放输出（无需重播当前曲目），且不产生明显咔嗒爆音，同时刷新已预加载的下一曲均衡计划

#### Scenario: 播放与暂停 300 ms 淡入淡出与响度均衡互不覆盖
- **WHEN** 同时开启「播放 / 暂停淡入淡出」与「响度均衡」并执行暂停与恢复操作
- **THEN** 淡出与淡入渐变结束后响度补偿保持原值不丢失，用户保存的软件音量不被篡改

#### Scenario: 无缝切歌时下一曲在边界准确切换响度计划
- **WHEN** 当前曲目自然播完并无缝衔接至预加载的下一曲（涵盖 `libmpv` 与 `AsioPlayer` 同采样率无缝边界）
- **THEN** 下一曲在曲目边界起即采用其对应的响度补偿与限幅策略，不残留上一曲增益

#### Scenario: 关闭响度均衡后恢复零滤镜与零限幅直通
- **WHEN** 用户关闭响度均衡
- **THEN** `libmpv` 清空响度音频滤镜链，`AsioPlayer` 完全旁路响度增益与限幅器，音频管线回到原有直通路径

#### Scenario: Sonos 投放不应用本机响度均衡
- **WHEN** 输出目标切换为 Sonos 房间进行投放播放
- **THEN** 本机响度均衡设置不干预 Sonos 音箱音量与音箱直连音频流

### Requirement: 设置持久化、设置页控制与曲目响度诊断展示
客户端 SHALL 持久化响度均衡相关设置，在设置页提供清晰的开关、档位及曲库中位数提示，并在曲目「查看信息」中展示响度与当前补偿以便听感校验。

#### Scenario: 重启应用后保留响度均衡设置
- **WHEN** 用户修改响度均衡开关、响度目标、对齐方式或峰值保护后重启应用
- **THEN** 应用从 `settings.json` 恢复完全一致的响度设置（旧版无此字段的配置文件默认关闭且回落默认档位）

#### Scenario: 设置页展示曲库中位数参考与 Sonos 边界说明
- **WHEN** 用户打开设置页「播放」分区
- **THEN** 可见响度均衡开关、明确注明仅作用于本机播放（不影响 Sonos 投放）的说明；开启后展示响度目标（附带服务端下发的曲库中位数参考）、对齐方式与峰值保护下拉项

#### Scenario: 曲目查看信息展示响度物理量与当前生效补偿
- **WHEN** 用户对已包含响度数据的曲目打开「查看信息」弹窗
- **THEN** 信息行展示该曲的集成响度（LUFS）、真峰值（dBTP）、专辑响度（若有）以及在响度均衡开启时当前生效的增益补偿与限幅状态
